# /leanflow:verify

保留给旧用法或用户希望单独核对结果的场景，日常不必单独调用。

读取 `${CLAUDE_PLUGIN_ROOT}/references/completion.md`，仅执行其中的「验证」。
优先使用参数或会话里已明确的 plan / 改动范围；无 plan 时检查当前改动，
范围有歧义才询问。复用仍有效的证据，缺失或失效的检查才重跑；
用户明确要求重跑时按其要求执行。

只检查、记录并集中报告结果：通过 / 失败 / 未验证 / 待人工确认。
需要修改代码的问题列出来，遵照已有修复授权处理，否则等用户决定。
不自动派完整复审、不自动归档，也不把本命令通过称为整个 feature 完成。
